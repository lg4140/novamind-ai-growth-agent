4. Better constraint UX: structured UI for channels, audience, CTA, no unsupported semantic guesses.
5. Redaction, retention and memory deletion controls.

3. Content/plan visual Diff Viewer, accessibility and browser interaction testing.
4. Error recovery UX, performance load tests, deterministic release CI and dependency lockfile.

No autonomous live marketing automation until these are met.
