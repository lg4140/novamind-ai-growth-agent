# Contributing

This repository is maintained as an AI Agent product-management portfolio prototype.

## Development

1. Use Python 3.11 or 3.12 and create a virtual environment.
2. Install `pip install -r requirements-test.txt`.
3. Run `python scripts/public_release_check.py`.
4. Run `python evals/run_offline_evals.py` and `python scripts/demo_offline.py`.
5. In pull requests, explain any changes to approval boundaries, evidence sourcing,
   synthetic-data labeling, and the no-live-sending policy.

Do not submit real customer data, private logs, credentials, or claims about measured
business impact without supporting evidence. Follow [SECURITY.md](SECURITY.md).

A license has **not yet been selected**; contact the repository owner before
reusing code beyond permissions granted by applicable law.
